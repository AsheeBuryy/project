# Tindahan ni Aling Rosa

Sari-sari store website for a neighborhood tindahan in the Philippines: product shelves, load/GCash services, and pickup checkout in Philippine pesos.

## Run

```bash
npm install
npm run dev
```

If Node.js is not installed, serve the static site with PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Open [http://localhost:5173](http://localhost:5173).
